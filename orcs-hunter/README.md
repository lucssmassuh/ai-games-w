# Orcs Hunter

Use Tab to cycle arrow types. Press 1/2/3 (top row or numpad), or click the matching Buy control, to buy and select one ordinary/explosive/triple arrow for 1/6/3 coins. The arrow type is selected even without enough coins; only the purchase requires sufficient coins. Selection and purchases stop after game over. Ordinary arrows also regenerate up to 20, one every two seconds.

Run purchase regression tests with `node --test orcs-hunter/tests/shop.test.cjs`.
